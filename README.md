# TM28500 · Boceto web

Boceto de web para un taller de coches deportivos en Arganda del Rey (Madrid).
Textos, opiniones y datos de contacto son de ejemplo.

- `index.html`: página principal (Tailwind)
- `configurador.html` + `modelo.glb`: configurador 3D (Three.js), incrustado en la sección "Configurador 3D"

Modelo 3D: "Porsche 911 GT3" por Outlaw Games, licencia CC BY-NC 4.0 (Sketchfab). Fotos: Unsplash.
